## 2. Top item: run the first idea round

Athmane will bring ideas generated by ChatGPT, DeepSeek and Adaptive AI with
`ideas/PROMPT_GENERATOR.md`, ideally already merged by ChatGPT with `ideas/PROMPT_NOVELTY_FILTER.md`.

1. **Add Claude's own batch:** 8 ideas written with the same prompt and the same card format.
2. **Verify novelty.** For every idea, run `scripts/arxiv_search.py` with two or three phrasings of
   its mechanism.
   - Open the closest hits and record them under "Closest prior work" as verified arXiv IDs.
   - Any reference given by another assistant that does not resolve is marked NOT VERIFIED and
     discarded.
3. **Triage** with the kill criteria K1–K7 of IDEAS.md. Every idea gets a register line: REJECTED
   with its criterion, or SHORTLISTED with the test that would decide it. Write the full idea cards
   in a new file `ideas/round-01.md`.
4. **Propose 2–3 shortlisted ideas** to Athmane. For each, give the cost in this benchmark (new data,
   new model, time) and what a win or a loss would teach. Athmane decides; do not start building an
   idea Athmane has not chosen.

If Athmane has not brought ideas yet, do steps 1–3 with Claude's batch only, so the pipeline is
exercised, and say so in the journal.
